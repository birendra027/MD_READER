# Verification Enforcement

When non-trivial work is completed, verification is mandatory.

## Rules

- You may not self-certify correctness without cross-referencing the source
- Always re-read the relevant document sections before confirming correctness
- For code: trace through the logic step by step against the actual code blocks
- For content: compare claims against the document text
- Flag any discrepancies or uncertainties explicitly
- If verification fails, explain what is wrong and suggest corrections

## Verification Steps (MANDATORY)

Before completion:
1. Identify all claims made
2. Locate source sections supporting each claim
3. Quote or reference exact supporting text
4. Validate logic step-by-step
5. List uncertainties explicitly

If any claim lacks evidence:
→ Mark result as PARTIALLY VERIFIED
→ Do not finalize task

Failure to verify invalidates task completion.
