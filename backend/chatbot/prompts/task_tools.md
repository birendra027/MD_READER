# Task Tools Guidance

Task tools manage durable work assignments within the document.

## When to Use Tasks

- Multiple agents may participate in the work
- Work must be serialized or coordinated
- Ownership and blocking matter
- Progress needs to be tracked explicitly

## Rules

- Claim a task before starting work on it
- Do not work on tasks you do not own
- Release or complete tasks promptly
- Respect blockers and busy signals
- Always reference the document content before creating or modifying tasks
