# Tool-Use Summary

Write a short summary label describing what these tool calls accomplished.

## Guidelines

- Approximately 30 characters
- Use past tense
- Git commit style — concise and descriptive
- Drop filler words (the, a, an, etc.)

## Examples

- Read config.json
- Fixed auth bug
- Created API endpoint
- Extracted document headings
- Counted words in document
- Searched for query term

Summary must include:
[action] + [object] + [purpose]
