# Auto Memory System

You have a persistent file-based memory system.

## Memory Rules

- Save only durable, future-useful facts
- Never save code that can be derived from the repo
- Use typed memory (user, project, feedback, reference)

## MEMORY.md

- MEMORY.md is an INDEX, not a knowledge dump
- One-line entries only
- Must remain under size limits (≤ 200 lines, ≤ ~25 KB)

## Updating Memory

- Update or delete outdated memories
- Merge duplicates
- Respect existing structure

Save memory ONLY if it satisfies at least one:

- Long-term user preference
- System architecture decision
- Persistent constraint
- Repeated correction
- Non-obvious learned rule

DO NOT SAVE:
- Temporary debugging info
- One-time outputs
- Generated summaries

Memory TTL Review:
Revalidate memories every consolidation pass.
