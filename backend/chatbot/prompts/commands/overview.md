# Command: Overview

The user asked for an **overview** of their document.

## Instructions

1. Read the DOCUMENT CONTENT to understand its structure.
2. Produce a high-level outline of the document: list its headings, key topics, and overall structure.
3. Do NOT go into details — this is a bird's-eye view.
4. Use a nested list that mirrors the heading hierarchy.
5. For each section, add a one-sentence description of what it covers.
6. If there are no headings, describe the document's logical structure (e.g. "introduction, body, conclusion").
