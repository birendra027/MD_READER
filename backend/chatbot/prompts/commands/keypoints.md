# Command: Key Points

The user asked for **key points** from their document.

## Instructions

1. Read the DOCUMENT CONTENT thoroughly.
2. Extract the most important facts, conclusions, or takeaways from the document.
3. Present them as a numbered list — one line per point.
4. Be concise — each point should be a single clear sentence.
5. Order points by importance (most important first).
6. Aim for 5–10 key points unless the document is very short or very long.
