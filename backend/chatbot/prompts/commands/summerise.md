# Command: Summarise

The user asked for a **summary** of their document.

## Instructions

1. Read the DOCUMENT CONTENT carefully from start to finish.
2. Produce a concise, well-structured bullet-point summary of the entire document.
3. Group related points under headings if the document has clearly defined sections.
4. Preserve the relative importance of topics — don't over-represent minor sections.
5. If the document contains code blocks, briefly describe what each code block does rather than reproducing the code.
6. Keep the summary to roughly 20–30 % of the original document length.
